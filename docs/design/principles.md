# 바톤 디자인 원칙 (v2, 2026-11-10)

> 조사 메모: 세션 네트워크 제한으로 nngroup.com, material.io, lawsofux.com, toss.im은 직접 읽지 못했다. 아래는 그 출처들이 오래 공개해 온, 업계에서 널리 검증된 원칙을 바탕으로 정리한 것이다. 출처명을 적어 두니 네트워크가 열리면 원문과 대조한다.

## 한 문장
**조용한 제주, 또렷한 한 가지.** 화면마다 사람이 해야 할 일은 하나다. 나머지는 물러난다.

## 근거가 된 원칙 (출처 → 바톤 적용)
| 원칙 | 출처 | 바톤에서 |
|---|---|---|
| 시스템 상태를 보여준다 | Nielsen 휴리스틱 #1 | AI가 쓰는 동안 진행 표시, 저장 후 토스트 "올라갔어요" |
| 현실 세계의 언어 | Nielsen #2 | "㎡" 옆에 "평", 금액은 "300만 원", 시스템 용어 금지 |
| 일관성과 표준 | Nielsen #4 | 아이콘 1세트, 모서리 반지름 2종(8·12), 버튼 2종 |
| 인식 > 기억 | Nielsen #6 | 올리기 3단계를 항상 상단에, 선택지는 보이게 |
| 미니멀 디자인 | Nielsen #8 | 카드당 라벨 1개, 첫 화면 모듈 3개 이하 |
| 선택지가 많을수록 결정이 느려진다 | Hick's Law | 첫 화면 CTA 1개, 도구는 3+3 |
| 큰 목표물이 빠르다 | Fitts's Law | 터치 목표 최소 44px, 휴대폰 하단 고정 CTA |
| 0.4초 안에 반응 | Doherty Threshold | 스켈레톤·즉시 토스트, 애니메이션 200ms 이하 |
| 비슷한 것은 가깝게 | Gestalt 근접성 | 라벨-값은 4px, 그룹 사이는 24px 이상 |
| 8pt 그리드, 명확한 타입 스케일 | Material 3 Layout / Apple HIG | 간격 4·8·12·16·24·32·48, 글자 12~40 7단계 |
| 한 화면 한 메시지, 넉넉한 여백, 큰 글자 | 토스 디자인(공개 가이드), 당근 | 히어로는 문장 하나, 본문 16px, 제목 28~40px |
| 사진이 먼저, 텍스트는 짧게 | 에어비앤비·당근 카드 | 4:3 사진 → 제목 1줄 → 가격. 배지는 1개 |
| 장식은 콘텐츠를 이기지 않는다 | Dieter Rams "Less, but better" | 일러스트는 배경·저채도, 글이 주인공 |

## 토큰 (style.css의 :root와 같아야 한다)
- **색**: 포인트 1개 감귤 `#ff6b1a`(낮) / `#ff8a3d`(밤). 중립은 따뜻한 회색 9단계. 상태색(성공/주의/위험)은 포인트가 아니다.
- **글꼴**: Pretendard Variable (한국어 가독성 1위, 토스·당근 등 사용). 제목 700~800, 자간 −0.02em. 숫자는 tabular.
- **스케일**: 12 / 13 / 14 / 16 / 18 / 22 / 28 / 40.
- **간격**: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64.
- **모서리**: 8(입력·버튼) · 12(카드·사진) · 999(칩). 그 외 금지.
- **그림자**: 떠 있는 것만(모달, 드롭다운, 호버한 카드). 정지한 카드는 그림자 없음, 1px 선 또는 배경 톤 차이로 구분.
- **아이콘**: 1.75px 선 아이콘 1세트(20px). 이모지는 UI에 쓰지 않는다. (오늘의 제주어 칩 하나만 예외)
- **움직임**: 150~250ms, ease-out. 밤의 등불 빛만 느리게(2.4s). reduce-motion 존중.

## 화면별 규칙
- **홈**: 히어로(문장 1 + 버튼 1 + 링크 1) → 빠른 실행 3 → 새 글(집·물건) → 제주 생활 3 → 프로젝트·해커톤. 통계는 히어로 아래 한 줄 회색 글.
- **카드**: 사진(없으면 톤 배경+아이콘) / 라벨 1개 / 제목 1줄(말줄임) / 보조 1줄 / 가격. 높이 동일.
- **상세**: 사진 갤러리 → 제목 → 핵심 사실 4칸 → 본문. 오른쪽(모바일은 하단 고정) 가격 + 버튼 1개 강조.
- **올리기**: 3단계 표시 항상 보임. 한 단계에 입력 7개 이하. 다음 행동 버튼은 하나.
- **문구**: 능동태, 짧게. 버튼은 동사("올리기", "문의하기"). 오류는 원인+해결.

## 하지 않는 것
- 이모지 제목·메뉴·버튼, 배지 2개 이상, 그라데이션 띠, 모든 블록에 그림자, 가운데 정렬 남발, 세 가지 이상 포인트 색.
