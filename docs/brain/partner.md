# 협업

목표: 제주도·기관·대학과 손잡기.

- 데이터: `config.json`의 `support`(기관 링크), `ads`(좌우 광고), `direction`(제주의 방향)
- 화면: 홈의 '제주의 방향', 좌우 광고
- API: `/api/config`
- 전담 에이전트: `market/lib/agents.js`의 `AGENTS.partner` (자기 데이터만 읽고, 숫자 → 제안)

규칙
- 기관 로고·표식은 쓰지 않는다. 공식 사이트 링크만.
- 광고에는 '광고' 표시.
