# 인사이트

목표: 논문·통계·정책을 창업자가 읽기 쉽게.

- 데이터: `data/insights.json` (category, points 3개 이하, url 필수)
- 화면: `board.html?kind=insight`, `post.html?kind=insight&id=`
- API: `/api/posts/insight`, 관리자 `/api/admin/posts/insight`
- 전담 에이전트: `market/lib/agents.js`의 `AGENTS.insight` (자기 데이터만 읽고, 숫자 → 제안)

규칙
- 원문 링크 없는 글은 올리지 않는다.
- 요약은 한 줄, 숫자는 원문에 있는 것만.
