# 마케팅 플랜 — 스레드(Threads) 중심

## 왜 스레드인가
- 글 기반, 한국 사용자 많음, 알고리즘이 새 계정에도 노출을 줌. 사진 1장 + 짧은 글이면 됨.
- 바톤의 글(집·물건·프로젝트)이 그대로 콘텐츠가 됨. **매일 올릴 재료가 자동으로 생긴다.**

## 계정 세팅 (첫날)
- 이름: 바톤 | 소개: "사진만 올리면 글은 AI가 써 드려요 🍊 제주 생활 장터 · 집·물건·프로젝트" | 링크: 사이트 주소
- 프로필 사진: 🏃 주황 배경 (사이트 파비콘과 동일)
- 고정 글: "바톤이 뭐예요?" 3줄 + 사이트 링크

## 글의 5가지 종류 (돌려가며)
| 종류 | 예시 | 목적 |
|---|---|---|
| **A. 생활 정보** | "제주시 월요일은 플라스틱 버리는 날 🗑️ 아이스팩은요? → (답)" | 저장·공유 유도, 신뢰 |
| **B. 새 글 소개** | "아라동 투룸, 서류 보니 42㎡(12.8평) 2011년 준공. 집주인 직접 등록 🏠" | 장터 유입 |
| **C. AI 시연** | "건축물대장 사진 한 장 → 30초 뒤 이렇게 됐어요 (전/후 캡처)" | 와 하는 반응, 가입 |
| **D. 제주 감성** | "오늘의 제주어: 맨도롱 또똣 = 따뜻하게 알맞게 ☕" | 팔로우, 호감 |
| **E. 해커톤·프로젝트** | "이번 주 열린 해커톤 5개 📅 끝나면 결과물은 바톤에" | 개발자·학생 유입 |

## 2주 콘텐츠 캘린더
| 일 | 글 | 종류 |
|---|---|---|
| 1 (월) | 바톤 소개 + "오일장신문에 글 쓰다 포기한 적 있으세요?" | 고정글 |
| 2 (화) | 월요일 배출 품목 + 아이스팩 Q&A | A |
| 3 (수) | 건축물대장 → AI 추출 전/후 캡처 | C |
| 4 (목) | 오늘의 제주어 | D |
| 5 (금) | 이번 주 해커톤 5개 | E |
| 6 (토) | 주말 플리마켓·장터 정보 (제주 생활 꿀팁에서) | A |
| 7 (일) | "한달살기 끝나고 짐 정리, 사진만 찍으면 끝" 물건 등록 시연 | C |
| 8 (월) | 이번 주 추천 1위 글 소개 | B |
| 9 (화) | 깨진 유리는 병류가 아니에요 (불연성) | A |
| 10 (수) | 집주인 인터뷰 한 줄: "글 쓰는 데 10분 걸리던 게 30초" (실제 후기 생기면) | B |
| 11 (목) | 오늘의 제주어 | D |
| 12 (금) | 수상작 도감에서 "한국에서 해볼 만한 것" 1개 | E |
| 13 (토) | 폐가전 무상수거 1599-0903 | A |
| 14 (일) | 2주 회고: 올라온 글 수, 가장 많이 본 글 | B |

→ 관리자 → 스레드 글 탭이 A·B·E 초안을 자동으로 만든다. C·D는 캡처와 함께 직접.

## 측정
- 스레드: 팔로워, 글당 조회, 프로필 링크 클릭
- 바톤: 대시보드의 일 방문 수가 스레드 글 올린 날 오르는지 (오르면 그 종류를 더)

## 하지 않을 것
- 광고비 집행 (첫 100명 전까지)
- 다른 커뮤니티에 홍보 글 도배 (신고·차단 위험)
- 예시 글을 실제처럼 소개하기 (반드시 "예시"라고 밝힌다)
