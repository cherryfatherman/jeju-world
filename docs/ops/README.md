## 바톤 한 줄
**올리기 귀찮은 것을 AI가 30초 만에 글로 써주는 제주 생활 장터.** 집·물건·프로젝트.

## 운영 원칙 5가지
1. **검증 먼저.** 새 기능은 돈 낼 사람 3명에게 물어본 뒤 만든다.
2. **거짓 정보 0.** AI가 쓴 글·추출값에는 항상 "원본 확인 필요"를 붙인다. 분리배출표는 공식 안내로 확인한 뒤 ✅로 바꾼다.
3. **매일 하나.** 스레드 글 1개, 받은 편지함 확인 1번. 이 두 개만은 하루도 거르지 않는다.
4. **사람이 먼저.** 문의는 24시간 안에 답한다. 글 내려달라는 요청은 즉시 처리한다.
5. **숫자로 결정.** 느낌이 아니라 `kpi.md`의 숫자가 다음 할 일을 정한다.

## 바로 쓰는 링크
- 관리자: `/admin.html` (대시보드 · 받은 편지함 · 스레드 글 생성)
- 사업 기록: `PROJECT.md` (결정 사항 전체)
