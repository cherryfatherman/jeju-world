| 기능 | 와 포인트 | 난이도 |
|---|---|---|
| **전/후 비교 슬라이더** | 서류 사진 ↔ 정리된 글을 드래그로 비교 (홈에 데모) | 낮음 |
| **오늘의 제주 브리핑** | 날씨·바람·공항·배출 요일을 매일 아침 한 문단 (공공데이터 키 필요) | 중간 |
| **집 위치 지도** | 읍면동 단위로 아까 만든 제주대 지도 위에 핀 (정확한 번지는 표시 안 함) | 중간 |
| **가격 계산기** | 비슷한 글들의 가격대 분포를 보여 주는 작은 차트 | 중간 |
| **음성으로 올리기** | 사진 올리고 말로 설명 → AI가 글 (어르신·농가) | 중간 |
| **감귤 수확 알림** | 농가가 "다음 주 수확" 예고 → 알림 신청자에게 미리 알림 | 낮음 |
| **인수 체크리스트** | 집·프로젝트 넘기기 전 확인 20문항, PDF 저장 | 낮음 |
| **다국어 보기** | 외국인 거주자용 영어·중국어 자동 번역 보기 | 낮음 |
