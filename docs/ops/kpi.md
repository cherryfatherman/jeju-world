# KPI — 숫자로 보는 바톤

## 북극성 지표
**"실제 사람이 올린 글 수 (주간)"** — 바톤의 가치는 올리기 쉬움에서 나온다. 이게 늘면 나머지는 따라온다.

## 매주 월요일 적는 표
| 주 | 방문(일평균) | 실제 글 | 문의 | 추천 ♥ | 스레드 팔로워 | 한 줄 메모 |
|---|---|---|---|---|---|---|
| 11/10~ | | | | | | 해커톤 발표 주 |
| 11/17~ | | | | | | |
| 11/24~ | | | | | | |

어디서 보나: 관리자 → 대시보드 (방문·글·문의·추천), 스레드 앱 (팔로워).

## 단계별 목표
| 단계 | 기준 | 그다음 |
|---|---|---|
| 0. 시연 | 해커톤 발표 완료, 사이트 공개 주소 | 스레드 계정 개설 |
| 1. 첫 사용자 | 실제 글 10개, 문의 3건 | 예시 글 숨기기 |
| 2. 반복 | 같은 사람이 2번째 글 올림 (3명) | 중개사 배지 시험 |
| 3. 돈 | 유료 기능 첫 결제 1건 | 사업자등록·결제 연동 |
| 4. 확장 | 주 30개 글, 방문 일 300 | 서귀포시 배출표 추가, 다른 지역 |

## 경고 신호 (이러면 멈추고 생각)
- 2주 연속 실제 글 0개 → 영업 대상이 틀렸거나 올리기가 어렵다. 중개사 3명과 통화.
- 문의는 오는데 거래가 안 됨 → 가격 표기나 신뢰 문제. 상세 페이지 점검.
- 방문은 느는데 글이 안 늘어 → 정보(제주 생활)만 보고 감. 정보 페이지에 "올리기" 유도 강화.
