# 섬업 본부: 큰 줄기와 AI 직원

화면: `/hq.html` (관리자 비밀번호 필요). 데이터: `market/data/hq.json`. 로직: `market/lib/agents.js`.

## 큰 줄기 7개 (모든 운영의 기준)

| 줄기 | 부서 | 목표 |
|---|---|---|
| 거래 | 거래부 | AI 서비스·해커톤 프로젝트가 다음 주인을 만난다 (본업) |
| 창업정보 | 창업정보부 | 제주에서 받을 수 있는 지원사업·자금을 한곳에 |
| 인사이트 | 인사이트부 | 논문·통계·정책을 창업자가 읽기 쉽게 |
| 해커톤 | 해커톤부 | 일정과 수상작을 다음 프로젝트의 씨앗으로 |
| 소통 | 커뮤니티부 | 모든 글에 추천(업)과 이야기 |
| 제주살이 | 제주살이부 | 도민이 매일 찾는 생활정보 |
| 협업 | 대외협력부 | 제주도·기관·대학과 손잡기 |

줄기·부서·직원·할 일은 3D 대시보드에서 고치면 바로 저장된다.

## 구조: 줄기마다 전담 에이전트 하나

직무(기획·카피·디자인)로 나누지 않는다. 줄기마다 전담 에이전트가 자기 데이터만 읽고 처음부터 끝까지 맡는다. 서로 부르지 않는다. 설계 근거는 `agent-design.md`.
아래 직원 이름은 전담 에이전트의 얼굴이다. 부서장이 그 줄기를 대표해 보고한다.

## 직원 17명

본부장 한라 → 부서장 7명(오름·다온·슬기·나래·여울·올레·누리) → 팀장 2명(마루·이음) → 팀원 7명(소랑·보름·가람·새별·다솜·바당·한울).
부서장은 본부장에게 보고하고, 팀장·팀원은 부서장에게 제안한다. 성격(persona)을 고치면 다음 회의 말투가 달라진다.

## 회의가 돌아가는 순서 (하루 1번 자동 + '지금 회의' 버튼)

1. **센서**: 데이터 파일에서 줄기별 숫자를 읽는다. 지어내지 않는다.
2. **제안**: 정해진 규칙이 숫자를 보고 부서별 할 일을 만든다. 같은 제목의 끝나지 않은 일은 다시 만들지 않는다.
3. **회의록**: 숫자가 지난 회의와 같고 새 제안이 없으면 건너뛴다(AI 토큰 0). 바뀌었을 때만 Gemini가 같은 숫자와 제안으로 대화를 쓴다. 25초 안에 답이 없으면 정해진 문장으로 대신한다.
4. **기록**: 할 일은 '제안' 상태로 쌓인다. 운영자가 진행·완료로 바꾸거나 지운다.

## 직원이 하는 일과 하지 않는 일

- 한다: 상태 점검, 할 일 제안, 회의록, 데이터 자동 갱신(해커톤·공고).
- 하지 않는다: 글을 고치거나 지우는 일, 사실을 새로 쓰는 일, 코드 수정. 사실 정보는 출처가 있어야 하고 운영자가 올린다.

## 코드까지 스스로 고치게 하려면

사이트 안의 직원은 제안까지만 한다. 제안을 실제 코드로 옮기는 일은 Claude Code 예약 작업으로 한다.
예약 작업 한 번의 지시문 예시:

> `PROJECT.md`와 `docs/ops/agents.md`를 읽고, `market/data/hq.json`에서 상태가 '제안'인 할 일 중 코드로 해결할 수 있는 것 하나를 골라 구현한다. 사실 정보는 출처 없이 쓰지 않는다. 끝나면 그 할 일을 '완료'로 바꾸고 `PROJECT.md`에 한 줄 기록한 뒤 커밋·푸시한다.
