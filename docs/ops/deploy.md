# 배포: 누구나 주소로 들어오는 사이트 만들기

섬업은 Node 서버로 돌아가서, 서버를 대신 켜 주는 곳(호스트)이 필요하다. 준비된 길은 두 가지다.

| | Vercel (추천) | Render |
|---|---|---|
| 주소만 있으면 누구나 접속 | 됨 | 됨 |
| 잠들지 않음 (첫 접속이 느리지 않음) | 됨 | 안 됨 (15분 쉬면 잠들고, 다시 켜지는 데 1분쯤) |
| 무료 | 됨 (개인·비상업용 요금제) | 됨 |
| 방문자가 남긴 추천·이야기·새 글이 계속 남음 | 저장소(무료)를 붙이면 됨 | 무료로는 안 됨 |

## Vercel로 올리기 (5분)

1. https://vercel.com 에서 GitHub 계정으로 가입한다.
2. **Add New → Project** 에서 `jeju-world` 저장소를 고르고 Import.
3. **Root Directory** 를 `market` 으로 바꾼다. (꼭. 사이트가 이 폴더 안에 있다)
4. **Environment Variables** 에 넣는다.
   - `ADMIN_PASSWORD`: 관리자 비밀번호. 새로 정한다. 없으면 관리자 로그인이 막힌다.
   - `GEMINI_API_KEY`: AI 글쓰기용. 새로 발급한 키만. 없으면 AI 글쓰기만 꺼진다.
   - `JEJU_CITS_CODE`, `JEJU_ITS_CODE`: 제주 교통정보센터 승인키. 없으면 도로 통제·전기차 충전소·관광지 구역이 숨겨진다.
5. **Deploy**. 끝나면 `https://….vercel.app` 주소가 나온다. 이후 GitHub main에 올릴 때마다 자동으로 다시 배포된다.

비밀번호와 키는 Vercel 화면에만 넣는다. 코드나 채팅에 적지 않는다.

## 방문자가 남긴 내용을 계속 남기기 (꼭, 3분)

**이걸 하지 않으면 올린 글이 보였다 안 보였다 하고, 눌렀을 때 "글을 찾을 수 없어요"가 뜬다.** 서버가 여러 대라서, 저장소가 없으면 글이 서버 한 대에만 남기 때문이다.

저장소를 붙이지 않으면 추천·이야기·새로 올린 글·관리자에서 고친 내용이 임시로만 남고, 서버가 새로 뜨면 처음 상태로 돌아간다. 사이트에 원래 들어 있는 글은 항상 그대로 보인다.

계속 남기려면:
1. Vercel 프로젝트의 **Storage** 탭 → **Upstash for Redis** 를 추가한다 (무료 요금제).
2. 프로젝트에 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 이 자동으로 들어간다.
3. **Deployments** 에서 Redeploy 한 번.
4. 확인: 추천을 누르고 몇 분 뒤 다시 들어와 숫자가 남아 있으면 된 것이다.

알아 둘 점: 저장소를 붙인 뒤 관리자에서 고친 파일은 저장소의 내용이 우선한다. 같은 파일을 코드(GitHub)에서 고쳐도 사이트에는 저장소 쪽 내용이 보인다.

## 키를 나중에 넣거나 바꿀 때

Vercel 프로젝트 → **Settings → Environment Variables** 에서 이름과 값을 넣고 저장한 뒤, **Deployments** 에서 맨 위 배포의 ⋯ → **Redeploy** 를 누른다. 다시 배포해야 새 키가 적용된다.
확인: 관리자 화면의 'AI 글쓰기 상태'와 '자동 갱신' 탭의 '제주 교통정보센터 연결 점검'.

서버 위치는 서울(`market/vercel.json`의 `icn1`)로 정해 두었다. 국내 공공 API가 해외 접속을 막는 경우가 있어서다.

## 한계

- Vercel에서는 한 번에 보낼 수 있는 크기가 4.5MB까지다. 사진을 여러 장 한꺼번에 올리면 실패할 수 있다(사진은 올리기 전에 자동으로 줄인다).
- Vercel에서는 서버가 계속 켜져 있지 않다. 그래서 자동 갱신(해커톤 일정, 본부 회의, AI 직원 근무)은 방문이 있을 때 주기가 지난 것만 돌고, 방문이 없어도 하루 한 번 예약 호출(`market/vercel.json`의 `crons`)로 돈다.
- Vercel 무료 요금제는 개인·비상업용이다. 돈이 오가는 서비스가 되면 유료로 바꾼다.
- 작업 환경에서는 Vercel에 직접 올려 보지 못했다. 같은 조건(프로그램 폴더 읽기 전용, 임시 폴더 저장, 가짜 저장소)으로 흉내 내어 확인했다. 실제 배포 화면에서 막히면 그 화면을 캡처해 알려 준다.

## Render로 올리기

저장소 맨 위 `render.yaml` 을 쓴다. https://render.com/deploy?repo=https://github.com/cherryfatherman/jeju-world 를 열고 `ADMIN_PASSWORD` 를 넣는다.
